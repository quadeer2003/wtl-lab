### **Required Concepts - TLDR**:

1. **JavaScript Date Object**:
   - The `Date()` object is used to get the current date and time.
   - Methods like `.getHours()`, `.getDate()`, `.getMonth()`, and `.getFullYear()` are commonly used to retrieve specific parts of the date and time.
   - [MDN Web Docs - Date](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Date)

2. **DOM Manipulation**:
   - JavaScript can interact with and modify HTML elements dynamically using the `document` object.
   - Common methods include `document.getElementById()` to select elements and `.innerHTML` to update their content.
   - [MDN Web Docs - DOM Manipulation](https://developer.mozilla.org/en-US/docs/Web/API/Document_object_model)

3. **Math.random() and Math.floor()**:
   - `Math.random()` generates a random floating-point number between 0 (inclusive) and 1 (exclusive).
   - `Math.floor()` rounds down a number to the nearest integer.
   - [MDN Web Docs - Math.random()](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Math/random)

4. **document.lastModified**:
   - This property returns the date and time when the document was last modified.
   - [MDN Web Docs - document.lastModified](https://developer.mozilla.org/en-US/docs/Web/API/Document/lastModified)
