### **How to Run**:
1. Save the code in an `.html` file (e.g., `dynamic_content.html`).
2. Open the saved `.html` file in a web browser (such as Chrome, Firefox, or Edge).
3. The page will display:
   - The current date and time.
   - A greeting message based on the time of day ("Good Morning" or "Good Afternoon").
   - A randomly generated "lucky number."
   - The date and time when the page was last modified.
