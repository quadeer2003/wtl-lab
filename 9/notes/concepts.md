

### **2. Required Concepts (TL;DR)**

#### Key Concepts:
1. **MVC Architecture**:  
   - **Model**: Stores data (`data` array in the code).  
   - **View**: Renders the UI (EJS templates).  
   - **Controller**: Handles routing and logic (Express routes).

2. **EJS (Embedded JavaScript Templates)**: A template engine that lets you embed JavaScript in HTML.

3. **Express.js**: A Node.js framework for handling HTTP requests, routes, and middleware.

#### Resources:
1. [EJS Official Documentation](https://ejs.co/)
2. [Express.js Guide](https://expressjs.com/en/starter/overview.html)
3. [MVC Pattern Overview](https://developer.mozilla.org/en-US/docs/Glossary/MVC)
