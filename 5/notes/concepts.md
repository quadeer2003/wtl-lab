### **1. How to Run**:
1. Save the provided HTML code as a `.html` file (e.g., `student_registration.html`).
2. Open the file in a web browser (e.g., Chrome, Firefox).
3. The page will display the student registration form.
4. After filling in the form, submit the form and the `validate()` JavaScript function will perform input validation before submission.

### **2. Required Concepts TLDR & Resource Links**:
- **HTML Forms**: Used to collect user input through various form elements such as text fields, checkboxes, and buttons.
   - [HTML Forms - MDN Web Docs](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/form)
  
- **JavaScript DOM Manipulation**: The use of JavaScript to dynamically manipulate HTML elements, such as reading input values or updating content on the page.
   - [DOM Manipulation - MDN Web Docs](https://developer.mozilla.org/en-US/docs/Web/API/Document_object_model)

- **Regular Expressions (RegEx)**: A sequence of characters used as a search pattern. In this script, RegEx is used to validate input like roll numbers, phone numbers, and email addresses.
   - [JavaScript Regular Expressions - MDN Web Docs](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Regular_Expressions)

- **JavaScript Validation**: The technique to validate user input on the client-side using JavaScript before submitting the form to the server.
   - [Client-Side Form Validation - W3Schools](https://www.w3schools.com/js/js_validation.asp)
