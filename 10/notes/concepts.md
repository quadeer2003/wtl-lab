### **2. Required Concepts (TL;DR)**

#### Key Concepts:
1. **JSX (JavaScript XML)**: A syntax extension for JavaScript used in React to describe UI structure.
2. **React Components**: Reusable pieces of UI, created as functions or classes.
3. **State and Props**: Mechanisms to manage and pass data in React applications.
4. **Inline Styles**: Applying styles directly to elements using the `style` attribute in JSX.
