### Critical Questions:

1. **What is DOM manipulation in JavaScript and how can it be used to modify HTML elements dynamically?**
   - DOM manipulation allows you to access and modify HTML elements through JavaScript. You can change content, styles, and behavior of elements, such as updating text, hiding/showing elements, or changing colors based on conditions.

2. **Why is form validation important in web development, and what are some common validation techniques?**
   - Form validation ensures that the data submitted through a form is accurate and formatted correctly. Common techniques include checking if required fields are filled, verifying email formats, confirming password matches, and restricting inputs to specific patterns (e.g., phone numbers or roll numbers).

3. **What are event listeners in JavaScript, and how do they differ from inline event handlers like `onclick`?**
   - Event listeners are functions attached to specific DOM elements to listen for specific events (e.g., clicks, focus, blur). They are generally more flexible and scalable than inline event handlers because they allow multiple handlers for the same event and are easier to manage, especially in larger codebases.

4. **How do the `onfocus` and `onblur` events help improve user experience in form fields?**
   - The `onfocus` and `onblur` events allow you to change the appearance of form fields when the user interacts with them, such as highlighting an input field when focused or resetting its appearance when the user clicks away. This provides visual feedback to the user.

5. **What is the role of JavaScript in handling mouse events like `onmouseover` and `onmouseout`?**
   - Mouse events like `onmouseover` and `onmouseout` are used to trigger specific actions when the user hovers over or moves away from an element. These events can be used to provide interactive feedback, such as displaying tooltips or changing styles dynamically.

6. **How can JavaScript dynamically disable or enable form elements like buttons or text areas?**
   - JavaScript can change the `disabled` attribute of form elements, effectively enabling or disabling them based on certain conditions. For example, the `ptadisplay()` function disables the "Permanent Address" textarea when a button is clicked.

7. **What is the significance of event bubbling and capturing, and how can they affect event handling in JavaScript?**
   - Event bubbling refers to how events propagate from the target element up to its ancestors in the DOM tree, while capturing works in the opposite direction. Understanding these concepts is important for managing events and controlling their flow, especially when using event delegation.

These questions and concepts will help you build a foundational understanding of JavaScript's role in dynamic web development, particularly in handling form validation and events.
