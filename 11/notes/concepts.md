### **2. Required Concepts (TL;DR)**

#### Key Concepts:
1. **React Functional Components**: Functions that return JSX to render UI elements.
2. **Props**: Used to pass data from a parent component to a child component.
3. **Forms in React**: Handling input fields and form submission in React components.
4. **List Rendering**: Dynamically creating elements (like a list) using `.map()`.
5. **Event Handling**: Handling events like clicks and form submissions in React using event handlers.
