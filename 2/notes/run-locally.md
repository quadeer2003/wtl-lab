

### 1. **How to Run**
   - **Requirements**: 
     - A text editor (e.g., Visual Studio Code, Sublime Text).
     - A browser (e.g., Google Chrome, Firefox).
   - **Steps**:
     1. Save each file with appropriate names, such as:
        - `index.html`
        - `vision.html`
        - `mission.html`
     2. Save the image `csed.jpeg` in the same directory as the HTML files.
     3. Open the `index.html` file in any browser to view the webpage. Links to `vision.html` and `mission.html` should work as expected.
