
### **2. Required Concepts (TL;DR)**  
#### Key Concepts:
- **Node.js**: A runtime for executing JavaScript outside the browser.
- **HTTP Module**: Used to create a web server (`http.createServer`).
- **OS Module**: Provides information about the operating system (`os.platform`, `os.arch`, etc.).
- **FS Module**: Enables file handling in Node.js (`fs.open`, `fs.writeFile`, etc.).
