## needs nodejs installed
1. Create folder "7" 
2. Open VS Code
3. Goto file->open folder "7" and select folder "7"
4. Click new file in the explorer window
5. Name the file as index.js
6. Type the code
7. Goto Terminal->New Terminal
8. In the terminal type node index.js and enter
9. Open webbrowser and type url localhost:8080
